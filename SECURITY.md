# Security

## Report a security problem

If you find a way to break into torus or get at someone else's account, please tell us privately. Do not open a public GitHub issue, because that shows the problem to everyone before it is fixed.

Email **security@torus.wtf** and include:

- what the problem is
- the steps to make it happen
- a fix, if you have one in mind

You should get a reply within 72 hours.

## What happens next

1. We confirm the problem and work on a fix, usually within two weeks.
2. We release the fix.
3. We publish a short note about it and credit you, unless you would rather stay unnamed.

torus is a small project and cannot pay rewards for reports.

## Which version gets fixes

Only the current version at [torus.wtf](https://torus.wtf), which is the `main` branch of this repository. If you run your own copy, keep it up to date with `main`.
